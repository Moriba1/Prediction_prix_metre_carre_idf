Projet Power BI – Analyse des données

1) Objectif du projet

Ce projet vise à analyser le marché immobilier en Île-de-France à travers des visualisations interactives réalisées avec Power BI, afin d’identifier les principaux facteurs influençant le prix au mètre carré des logements.


2) Contenu du repository

* `rapport.pbix` : Fichier Power BI complet
* `images/` : Captures d’écran du dashboard
* `README.md` → Conclusions

---

3) Dataset

* Source : data.gouv.fr
* Type de données : Transactions immobilières
* Période : Année 2025

---

4) KPI analysés

- Prix moyen au m2
- Nombre de transactions
- Répartition des biens par nombre de pièces
- La somme des prix du m2
---

5) Insights principaux

- Paris (75) présente les prix au m2 les plus élevés, tandis que la Seine-et-Marne (77) est le département le plus abordable
- La Seine-et-Marne (77) enregistre le plus grand nombre de transactions immobilières
- Un pic d’activité est observé en avril 2025
